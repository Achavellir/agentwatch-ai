# AgentWatch local tool lab

## What changed

The original demonstration generated event records directly. This extension performs actual reads and writes against a temporary fixture directory, then records metadata through `TraceWriter`. The fixture is created by the lab and deleted when the run finishes. Your documents, browser history, and credentials are not used.

The driver is scripted Python, not an autonomous AI agent. The analyzer still uses local Isolation Forest machine learning. No LLM, paid API or network call is involved. This is a first instrumentation milestone toward a future controlled agent experiment, not completion of real-agent validation.

## Run

From the repository with its existing environment activated:

```sh
python local_lab.py --output reports/my-lab-run
python -m unittest discover -s tests -v
```

Choose a new output directory each time. Existing directories are rejected so previous evidence cannot be silently overwritten or mixed into a later run. Open `report.html` in the output directory. `evaluation.json` summarizes signals, and `manifest.json` records scenario labels separately from the detector input.

Python on macOS/Linux is required for the wrapper's `O_NOFOLLOW` file protection. No new dependencies are required.

## Experiment design

- 60 baseline sessions, generated by a fixed scripted schedule with seed 1201.
- 20 normal evaluation sessions, using seed 1202. Each session performs 2–8 real reads and 0–2 real writes.
- One deliberately unapproved write to a disposable fixture. The driver has authorized this experiment; “unapproved” means no grant in the lab's simulated application policy.
- One benign stress session: 80 reads and one approved write. This is not an attack and must not count toward attack detection.

Session and event IDs are disjoint across training and evaluation. Labels remain in the manifest and are not passed to `analyze`. Both sets share a scripted task family and fixture; different seeds alone do not make an independent benchmark. Approval comes from the runner's fixed grant set, not a model's claim. Local file reads/writes have zero outbound network bytes.

## Observed October 12, 2026

| Evaluation group | ML alerts | Rule alerts | Combined alerts |
|---|---:|---:|---:|
| 20 normal sessions | 1 | 0 | 1 |
| 1 designed policy violation | 0 | 1 | 1 |
| 1 benign stress session | 0 | 0 | 0 |

The observed normal-session alert fraction is 1/20 (5%). It is not an estimate of production performance. Do not compare it as an improvement over the earlier synthetic 5/40 result: the datasets and workloads differ.

The rule detects the missing approval as expected. ML does not detect that policy violation or flag the stress case. This limited result provides no evidence of additional security detection value from ML in this lab. The model and its threshold were not tuned against these evaluation sessions.

## Boundaries and next experiment

The wrapper rejects path traversal and symlinks and uses only a private temporary fixture workspace in the runner. This is not an operating-system sandbox and is not designed to execute untrusted code, concurrent writers, shell commands, or arbitrary agent programs. Failed operations are not recorded. A logging failure after a successful operation can leave incomplete telemetry; transactional audit logging is future work. The wrapper intentionally records the designed policy violation after execution, so it is not a preventive control.

Tests cover real read/write effects, metadata-only logging, traversal and symlink rejection, failed-read behavior, trusted approval labeling, train/test separation, report generation, and refusal to overwrite prior runs.

Next: connect an explicitly authorized model runner to these bounded tools, record failures as well as successful actions, diversify task families, and define an independent holdout before further threshold changes. A model runner, separate task-family evaluation, and real-agent security results are not implemented yet. No paid experiment or public post is scheduled by running this lab.
